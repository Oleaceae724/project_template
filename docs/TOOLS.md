# Tools

Document required and optional tools for this project.

## Required tools

- Git
- Code editor or AI coding environment
- Runtime/package manager: TBD

## Optional tools

- GitHub connector
- Browser automation or visual testing tools
- Local screenshot tools
- Mobile emulator tools for mobile projects only

## Tooling rules

- Do not commit API keys, tokens, credentials, or local auth files.
- Do not commit machine-specific absolute paths.
- Do not require optional AI plugins unless the project genuinely depends on them.
- Prefer repo-local docs and prompts over hidden chat-only instructions.

## AI workflow note

Reusable AI Skills or Plugins should generally live outside this project repo. This repo should contain portable prompts and project-specific instructions only.
