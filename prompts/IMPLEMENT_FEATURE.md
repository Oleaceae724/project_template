# Implement Feature Prompt

Use this when implementing a scoped feature.

```md
Implement this feature:
[feature description]

Success criteria:
- [criterion 1]
- [criterion 2]
- [criterion 3]

Constraints:
- Keep changes focused and reviewable.
- Do not modify unrelated behavior.
- Do not add dependencies unless justified.
- Update docs if behavior, commands, or architecture change.

Before coding, provide a short plan.
After coding, run relevant validation and summarize:
1. What changed.
2. Files touched.
3. Validation run and results.
4. Risks or follow-ups.
5. Docs updated.
```
