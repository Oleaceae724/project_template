# Plan Only Prompt

Use this when you want planning but no code changes.

```md
Plan only. Do not edit files or run destructive commands.

Task:
[describe task]

Please review relevant docs/code and produce:
1. A concise problem statement.
2. Recommended approach.
3. Files likely affected.
4. Step-by-step implementation plan.
5. Acceptance criteria.
6. Validation plan.
7. Risks and tradeoffs.
8. Open questions.

Be direct about anything that seems overcomplicated or risky.
```
