# Review Code Prompt

Use this for a code review pass.

```md
Please review the current code or recent changes.

Focus on:
1. Bugs or logic errors.
2. Broken edge cases.
3. Overly large or confusing files.
4. Duplicated logic.
5. Weak or missing validation.
6. Security or data-loss risks.
7. Places where the implementation diverges from docs or product intent.

Do not edit files yet.

Output:
- Critical issues
- Important improvements
- Nice-to-have cleanup
- Suggested validation
- Recommended next steps
```
