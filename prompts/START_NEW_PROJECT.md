# Start New Project Prompt

Use this when beginning a new app from this template.

```md
I am starting a new project from this template.

Please read `AGENTS.md` and the files in `docs/`.

Goal:
[describe the app]

Likely project type:
[local browser app / desktop app / web app / mobile app / other]

Please do not write application code yet.

First, help me:
1. Fill out the missing project docs.
2. Choose a simple tech stack appropriate for the goal.
3. Propose the initial folder structure.
4. Define run/test/build commands.
5. Break the MVP into small implementation phases.
6. Identify risks, assumptions, and open questions.

Output a setup plan and list the files you recommend creating or editing.
```
