# Start Session Prompt

Use this at the beginning of an AI coding session.

```md
Please start by reading:

- `AGENTS.md`
- `docs/PRODUCT.md`
- `docs/IMPLEMENTATION_PLAN.md`
- `docs/ARCHITECTURE.md`
- `docs/TESTING.md`
- `docs/SESSION_HANDOFF.md`

Session goal:
[describe the task]

Before coding, summarize:
1. What you understand the goal to be.
2. What files or areas are likely involved.
3. The smallest safe implementation plan.
4. Risks or assumptions.
5. Any blocking questions.

Do not make code changes until the plan is clear.
```
